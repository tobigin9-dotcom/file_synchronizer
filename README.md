# Сервис синхронизации файлов с Яндекс Диском

Фоновая программа следит за папкой на компьютере и приводит папку на
Яндекс Диске к тому же виду: новые файлы загружаются, изменённые
перезаписываются, удалённые — удаляются. При запуске выполняется первая
полная синхронизация. Подпапки не отслеживаются.

## Установка

    pip install -r requirements.txt

## Настройка

1. Создайте на Яндекс Диске папку для резервных копий.
2. Получите OAuth-токен с правами на Диск (https://yandex.ru/dev/disk/poligon/).
3. Скопируйте `.env.example` в `.env` и заполните его (`.env` в `.gitignore`):

| Параметр       | Описание                                   |
|----------------|--------------------------------------------|
| `LOCAL_FOLDER` | путь к синхронизируемой папке              |
| `CLOUD_FOLDER` | имя существующей папки на Яндекс Диске     |
| `TOKEN`        | OAuth-токен                                |
| `PERIOD`       | период синхронизации, секунды              |
| `LOG_FILE`     | путь к файлу лога                          |

## Запуск

    python main.py

Остановка — `Ctrl+C`. Ошибки сети и чтения файлов пишутся в лог
(уровень ERROR) и не останавливают программу. При неверном токене,
отсутствующей папке или некорректном `.env` программа завершается
с понятным сообщением.

## Структура

- `main.py` — запуск, проверка параметров, основной цикл;
- `config.py` — чтение `.env` (python-dotenv);
- `synchronizer.py` — сравнение папки и хранилища по времени изменения, логирование (loguru);
- `yandex_disk.py` — класс `YandexDiskStorage` с методами `load`, `reload`,
  `delete`, `get_info` (вся работа с конкретным хранилищем).
